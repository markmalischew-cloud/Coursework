# ЛР 3, часть 1 — Java (язык с управляемой памятью)

Проект «Герой и инвентарь» из ЛР 2, перенесённый на Java.
Память освобождает сборщик мусора; деструктора нет, ресурсы освобождаются
через `AutoCloseable` и try-with-resources.

## Требования

- JDK 17+ (`java -version`, `javac -version`)

## Сборка

    javac -d out java/src/*.java

## Запуск

    java -cp out game.Main

Если в консоли Windows вместо русских букв «?»:

    chcp 65001
    java -Dstdout.encoding=UTF-8 -cp out game.Main

## Что демонстрирует программа

1. **Композиция** — `Hero` сам создаёт `Inventory` в конструкторе и наружу не отдаёт.
2. **Агрегация** — предметы (`Item`) создаются снаружи и передаются в инвентарь.
3. **Проверка правил** — неверные параметры, дубликаты, нехватка золота, плохие имена.
4. **Ссылки и копии** — `second = first` копирует ссылку, а не объект; изменение через
   `second` видно через `first`; `==` сравнивает ссылки.
5. **Освобождение ресурса** — `AdventureLog` реализует `AutoCloseable`;
   try-with-resources гарантированно вызывает `close()` при выходе из блока,
   но сам объект остаётся жив (память освободит GC).
6. **Сборщик мусора** — объект без ссылок уничтожается не при выходе из блока,
   а после `System.gc()`; видно через `WeakReference`.

## Структура

    game/
      Hero.java          — герой (композиция: Inventory по значению)
      Inventory.java     — инвентарь (агрегация: List<Item>)
      Item.java          — предмет
      ItemType.java      — тип предмета (enum)
      ItemRarity.java    — редкость предмета (enum)
      AdventureLog.java  — журнал (AutoCloseable)
      MemoryDemo.java    — демонстрации памяти
      Main.java          — точка входа
