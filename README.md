# Лабораторная работа №2: Объектно-ориентированное программирование на C++
**Тема:** Проектирование классов, управление памятью, Композиция и Агрегация.

## Описание проекта
Данный проект представляет собой модуль игровой системы на языке C++, демонстрирующий основные принципы ООП, разницу между композицией и агрегацией, а также работающий с динамической и статической памятью.

### Архитектура системы:
Проект находится в пространстве имён `game` и включает в себя три ключевых класса:
1. **`Item` (Предмет):** Сущность данных (название, тип, редкость, цена). Содержит валидацию входных данных (поддержка UTF-8 / кириллицы).
2. **`Inventory` (Инвентарь):** Класс для хранения массива указателей (`Item*`). 
   * **Агрегация:** Инвентарь не владеет временем жизни предметов. Предметы создаются снаружи в куче (`new`) и передаются в инвентарь по указателю. При уничтожении инвентаря предметы остаются в памяти.
   * **Rule of Five:** Операции копирования и перемещения явно запрещены (`= delete`) для предотвращения двойного освобождения памяти.
3. **`Hero` (Герой):** Основная сущность персонажа (имя, здоровье, мана, золото).
   * **Композиция:** Содержит поле `Inventory m_inventory` по значению. Время жизни инвентаря строго привязано к герою: при уничтожении героя автоматически вызывается деструктор инвентаря.


## Требования к сборке
* **Компилятор:** `g++` (GCC) 10+ или `clang++` с поддержкой стандарта **C++20**.
* **ОС:** Linux (Ubuntu/Debian), macOS или Windows (MinGW/WSL).
