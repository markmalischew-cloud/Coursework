# ЛР 3, часть 2 — C++ (умные указатели)

Проект «Герой и инвентарь» из ЛР 2, переведённый на умные указатели
(`std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`).
В проекте нет ни одного `new` и ни одного `delete`.

## Требования

- Компилятор с поддержкой C++17 (`g++`, `clang++`, MSVC)
- Чтобы компьютер хламом не был

## Запуск

    ./game

Windows:

    game.exe

## Что демонстрирует программа

1. **Композиция** — `Inventory` хранится в `Hero` по значению (самый надёжный вид владения).
2. **Агрегация** — предметы создаются снаружи и удерживаются инвентарём через `shared_ptr`.
3. **`unique_ptr`** — единоличное владение: объект уничтожается при выходе из блока
   без `delete`; владение передаётся через `std::move`, после чего исходный указатель пуст.
4. **`shared_ptr`** — разделяемое владение: `use_count()` растёт при копировании
   и уменьшается при уничтожении копии; объект уничтожается вместе с последним владельцем.
5. **`weak_ptr`** — наблюдатель: `m_equipped` в `Hero` не владеет предметом;
   `lock()` возвращает непустой указатель, пока предмет жив, и пустой после
   уничтожения последнего владельца; результат проверяется.

## Структура

    hero.hpp / hero.cpp            — герой (композиция: Inventory по значению; weak_ptr на экипировку)
    inventory.hpp / inventory.cpp  — инвентарь (shared_ptr на предметы)
    item.hpp / item.cpp            — предмет
    main.cpp                       — точка входа и демонстрации умных указателей

## Владение

| Где | На что | Кто владеет | Указатель | Почему |
|---|---|---|---|---|
| `Hero::m_inventory` | `Inventory` | `Hero` | поле по значению | композиция |
| `Inventory::m_items[]` | `Item` | инвентарь | `shared_ptr` | инвентарь удерживает предметы |
| `Hero::m_equipped` | `Item` | никто (наблюдатель) | `weak_ptr` | герой экипирует, но не владеет |
| `main`: `sword`, `potion`, `ring` | `Item` | `main` + инвентарь | `shared_ptr` | разделяемое владение |
| `DemoUniquePtr`: `hero`, `first`, `second` | `Hero` | единолично | `unique_ptr` | один владелец, передача через `std::move` |
